# Diagram Mapping

نگاشت شکل‌های معنادار PDFها به دیتاست‌ها.

## یادداشت مهم

- فایل‌های PNG در `sources/extracted/figures/` **محلی و قابل بازتولید** هستند.
- برای استخراج، ابتدا `pip install pymupdf` سپس `python scripts/extract_figures.py`.
- اسکریپت با فیلتر ابعاد (>= 100x100)، حجم (>= 5KB) و hash اجرا می‌شود.
