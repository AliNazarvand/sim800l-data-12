4.3.2. Sleep Mode (AT+CSCLK=1) 
 
User can control SIM800L module to enter or exit the sleep mode (AT+CSCLK=1) by DTR signal. When 
DTR is in high level and without interrupt (on air and hard ware such as GPIO interrupt or data in serial port), 
SIM800L will enter sleep mode automatically. In this mode, SIM800L can still receive paging or SMS from 
network but the serial port is not accessible. 
 
Note: Autobauding is default. It cannot enter sleep mode in the absence of synchronous serial port baud rate 
after module power on.  
 
4.3.3. Wake Up SIM800L from Sleep Mode (AT+CSCLK=1) 
 
When SIM800L is in sleep mode (AT+CSCLK=1), the following methods can wake up the module: 
z Pull down DTR pin. 
    The serial port will be active after DTR pin is pulled to low level for about 50ms. 
z Receive a voice or data call from network. 
z Receive a SMS from network. 
z Receive external interrupt
